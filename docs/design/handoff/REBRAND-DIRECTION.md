# Musterd rebrand direction

Status: **product rename in flight**; visual type pending bot confirmation (Don hit Claude session limits; follow-up on ChatGPT/Cursor). Interim below locks what we can from Don’s keep-Basel call + the Open Foundry catalog.

## 1. Verdict

**Evolve Basel** — keep the Swiss information-system grid, signal-only mustard, unboxed turns, mono ledger, and composer tool bar; refresh type from Open Foundry so the desk is no longer “Geist by default / feels like OpenMausBot.”

## 2. Type from Open Foundry (interim — confirm with Sal/Don)

| Role | Face | Why |
| --- | --- | --- |
| UI sans | **Work Sans** (Wei Huang) | OF-listed; neo-grotesque workhorse close to the Swiss “Helvetica job” without staying on Geist |
| Display (empty lockup / wordmark) | **Cooper Hewitt** (Chester Jenkins) or **Cotham Sans** | OF-listed; stronger desk identity than UI sans at 56px |
| Mono | **Office Code Pro** | OF-listed; ledger / steps / machine facts |

Fallbacks until files are vendored: system UI stack / `ui-monospace`. Do not invent faces outside [open-foundry.com/fonts](https://open-foundry.com/fonts).

## 3. Colour

**Keep mustard as the one signal colour** (focus ring, needs-you, approval border, Allow once). No washes, no hover tint, no brand warmth. Identity hues stay cooled away from mustard (already shipped).

## 4. Chrome (three moves)

1. Midnight/Daylight `--font-sans` / `--font-mono` → Work Sans + Office Code Pro (self-host OF files or licensed CDN).
2. Empty-team wordmark uses display face; mark stays ink-only bars.
3. Appearance font picker gains Work Sans (and optional Cooper Hewitt) as first-class ids alongside skin/system/Inter.

## 5. Copy tone

**Musterd** = the local crew desk: short, operator-grade, no cloud-poster voice. People read Musterd; `omb` / `openmausbot` remain compatibility aliases.
